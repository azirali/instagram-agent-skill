# Carousel and Story sequence

Choose the format from the user's request and material. A carousel should develop one useful idea across its slides; a Story sequence may support a timely update or question. Do not stretch thin material to a fixed slide count.

## Build from evidence

Start with the audience's question and the source supporting the answer. Build a sequence such as problem, visible example, explanation, practical takeaway and optional next action. Change that structure when the material calls for something else. Distinguish a mockup from a working feature and a proposal from a measured result.

Return each slide's purpose, headline, short body, visual instruction and alt text. Indicate which source or supplied image supports its claim. If assets are missing, provide a storyboard; do not describe it as finished image files.

For product screenshots, remove private account information and use demo data with clear labels where needed. Preserve logos and source credits accurately. Do not use an unrelated person's face, customer quote or third-party brand to imply endorsement.

## Fit the screen and language

Use the intended publishing surface and verify its current size/crop requirements during asset production. Keep copy short enough to read on a phone and allow space for interface overlays. Review rendered slides at phone size rather than trusting a word-count rule.

Prepare separate RU/EN/KK layouts if those languages are requested. Kazakh and Russian may wrap differently from English; adjust composition without shrinking text until it becomes unreadable. Confirm all localized versions carry the same factual claims and level of certainty.

When rendering is requested, use the available design tool or produce editable SVG/HTML assets suitable for the chosen workflow. Deliver actual paths and inspect the exports. If only copy was requested, copy and layout directions are sufficient.

Finish with the full sequence, asset status and any unresolved source or rights issue. Do not publish, create accounts, purchase assets or start paid generation as an implied part of writing a carousel. Specific authorization already given by the user remains valid.
